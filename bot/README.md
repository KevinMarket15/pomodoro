# 🍅 蕃茄鐘 Telegram 機器人：設定說明

設定好之後，**網頁關著也會在 Telegram 收到**：
- 計時結束
- 定時提醒、每天記帳提醒
- 秘書的關心：一陣子沒計時來問你要做什麼、休息太久（預設 30 分鐘）來關心你、晚上回顧今天

你也可以直接在 Telegram 打字：

| 打這個 | 會做什麼 |
|---|---|
| `120 午餐` | 記一筆支出，記到上次用的帳戶，之後可以按按鈕改帳戶或取消 |
| `開始` | 開始專注。任務條有任務就做第一個，沒有的話我會建議幾個讓你選 |
| `開始 寫報告` | 直接開始做「寫報告」 |
| `任務` | 列出建議的任務和任務庫的類別，點了可以開始、只做 5 分鐘或排進任務條 |
| `在看直播` | 開頭打「在」（或「正在」），就把「看直播」排進任務條，之後可以按「現在開始」或「取消」 |
| `暫停`、`繼續`、`結束`、`休息` | 控制計時 |
| `狀態`、`今天` | 看現在在做什麼、今天的成績 |

機器人和網頁用同一份雲端資料，打開網頁時會自動同步。

全部免費：Telegram、Cloudflare Workers（免費方案，不用信用卡）、Firebase（維持原本的免費方案）。

---

## 第 1 步：建立 Telegram 機器人

1. 在 Telegram 搜尋 **@BotFather**（有藍色勾勾的那個），按「開始」。
2. 傳 `/newbot`。
3. 它會先問名字：取一個顯示用的名字，例如「我的蕃茄秘書」。
4. 再問帳號：要用英文，結尾是 `bot`，例如 `my_tomato_secretary_bot`。被用掉的話換一個。
5. 成功後它會給你一串**權杖**，長得像 `1234567890:AAH...`。先複製起來，第 4 步會用到。

> 權杖就像密碼：拿到的人可以控制你的機器人，不要傳給別人。

## 第 2 步：下載 Firebase 服務帳戶金鑰

機器人要靠這把金鑰讀寫你的蕃茄鐘資料。

1. 打開 [Firebase 主控台](https://console.firebase.google.com/)，點專案 **pomodoro-2cd61**。
2. 左上角齒輪 ⚙ →「專案設定」→ 上方的「**服務帳戶**」分頁。
3. 按「**產生新的私密金鑰**」→「產生金鑰」，會下載一個 `.json` 檔，通常在「下載」資料夾。

> 這個檔案可以讀寫你所有的蕃茄鐘資料。不要傳給別人，也**不要放進蕃茄鐘的專案資料夾**，因為那個資料夾會上傳到 GitHub。設定完成後可以刪掉。

## 第 3 步：註冊 Cloudflare

到 [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) 註冊免費帳號，不用信用卡。註冊完記得去信箱點確認信。

## 第 4 步：把機器人放上 Cloudflare

在電腦上打開 PowerShell，**一行一行**執行（每行跑完再跑下一行）。指令用 `npx.cmd` 而不是 `npx`，因為 Windows 預設會擋 `npx` 這種指令碼：

```powershell
cd "C:\雜七雜八\網頁\Tomato\bot"
```

```powershell
npx.cmd wrangler login
```
第一次會問要不要安裝 wrangler，輸入 `y` 按 Enter。接著會打開瀏覽器，登入 Cloudflare 後按「Allow」。

```powershell
npx.cmd wrangler deploy
```
第一次會請你幫自己的網址取一個名字（workers.dev 子網域），隨便取一個英文名字。完成後會顯示機器人的網址，像 `https://pomodoro-bot.你取的名字.workers.dev`，記下來。

接著設定三個金鑰。每行執行後會叫你貼上內容，貼上後按 Enter：

```powershell
npx.cmd wrangler secret put TELEGRAM_TOKEN
```
貼上第 1 步的權杖。

```powershell
npx.cmd wrangler secret put FIREBASE_UID
```
貼上你的**帳號編號**：打開蕃茄鐘網頁 → 右上角 💬 秘書 → 最下面「🤖 聊天機器人」→ 按「複製」。

最後是第 2 步下載的金鑰檔。把下面這行的檔名換成你下載的檔名再執行：

```powershell
Get-Content "$HOME\Downloads\pomodoro-2cd61-firebase-adminsdk-xxxxx.json" -Raw | npx.cmd wrangler secret put FIREBASE_SA
```

> 不知道確切檔名的話，可以先執行 `dir "$HOME\Downloads\*firebase*"` 看看。

## 第 5 步：檢查並連結

1. 用瀏覽器打開第 4 步的機器人網址，會看到一張檢查表。
2. 全部 ✅ 之後，點最後一行的 `t.me/...` 連結打開 Telegram，按「開始」（或傳 `/start`）。
   **第一個傳 /start 的人會被當成主人**，所以建立好就馬上去傳。
3. 機器人回「連結好了！」就完成了。輸入框下面會出現「開始、暫停、結束…」的按鈕。

有 ❌ 的話照上面的說明修正，再重新整理那一頁。

## 第 6 步：選擇要不要主動傳訊息

網頁 💬 秘書 →「🤖 聊天機器人」→「主動訊息傳到」：
- **Telegram**（預設）：網頁關著時也會收到計時結束、提醒和秘書的關心。
- **不傳**：機器人不主動找你，但你傳給它的指令照樣能用。

同一個地方的「休息多久來關心」：從休息開始算，預設 30 分鐘，之後每隔這麼久再問一次，一段休息最多問 3 次；設成 0 就不問。

秘書的時段、多久沒計時來問、語氣、晚上回顧，都和網頁共用同一份設定。

## 常見問題

**網頁開著的時候，會收到兩次提醒嗎？**
會。網頁和機器人各自提醒一次，計時結束也一樣，但記錄不會重複。

**提醒會準時嗎？**
機器人每分鐘檢查一次，最多可能晚 1 分鐘左右。

**怎麼更新機器人？**
有新版本時，在 `bot` 資料夾執行 `npx.cmd wrangler deploy` 就好，金鑰不用重設。

**想換一個 Telegram 帳號連結？**
在已經連結的聊天室傳 `/unlink`，再用新帳號傳 `/start`。

**會用掉多少免費額度？**
- Cloudflare：每天約 1,500 次請求，免費額度是 10 萬次。
- Firebase：每天約 6,000 次讀取，加上網頁本身的用量，免費額度是每天 5 萬次。
